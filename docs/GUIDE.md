# Пошаговый гайд: как запустить бота для Яндекс Музыки

Этот гайд для тех, кто не программист. Все команды можно просто копировать и вставлять.
Займёт примерно час. Большую часть времени придётся ждать, пока что-то скачается.

**Что получится в итоге.** Твой личный бот в Telegram. Через него можно:
- искать и скачивать треки, альбомы и плейлисты из Яндекс Музыки;
- загружать в Яндекс Музыку свои аудиофайлы;
- открыть «Медиатеку»: приложение прямо внутри Telegram с плейлистами, плеером, скачиванием и загрузкой файлов.

## Что понадобится

- **Telegram** на телефоне или компьютере.
- **Аккаунт Яндекса с подпиской Плюс.** Без Плюса бот сможет скачивать только короткие отрывки.
- **Компьютер** с Windows или macOS. Он нужен только для настройки, дальше бот живёт на сервере.
- **Сервер (VPS)**: арендуешь его в шаге 2. Это недорого, обычно пара сотен рублей в месяц.

### Как это устроено
Бот — это программа, которая должна работать круглосуточно. Поэтому её ставят не на свой компьютер, а на арендованный сервер в интернете.
Сервер общается с Telegram и с Яндекс Музыкой. «Медиатека» — это веб-страница, которую открывает тот же сервер.
Telegram требует для таких страниц защищённый адрес `https://...`. Его мы бесплатно получим в шаге 8.

## Шаг 1. Создай бота в Telegram

1. Найди в Telegram **@BotFather** (у него синяя галочка) и нажми **Start**.
2. Отправь ему `/newbot`.
3. Он спросит **имя** бота. Это то, что видно в чате, например `Моя музыка`.
4. Потом спросит **username**: латиницей, он должен заканчиваться на `bot`, например `my_music_2024_bot`. Если имя занято, придумай другое.
5. BotFather пришлёт **токен**: длинную строку вида `7123456789:AAHk3...`.
   Скопируй её в заметки, она понадобится в шаге 5.

> [!WARNING]
> Токен — это ключ от бота. Никому его не показывай.

---

## Шаг 2. Арендуй сервер (VPS)

Подойдёт любой хостинг, где можно взять **VPS** (его ещё называют «виртуальный сервер» или «облачный сервер»).
При заказе выбери:

| Параметр | Что выбрать |
|---|---|
| Операционная система | **Ubuntu 24.04** (или 22.04) |
| Процессор / память | 1 ядро, **1–2 ГБ** оперативной памяти (2 ГБ лучше, если будешь загружать FLAC) |
| Диск | от 10 ГБ |
| Где находится | **Россия или Казахстан.** В России доступен весь каталог Яндекс Музыки, но с некоторых российских серверов не открывается Telegram. В Казахстане обычно работают оба сервиса. Связь проверишь в конце шага 3 |

После создания сервера хостинг покажет (в панели или письмом):
- **IP-адрес**: четыре числа через точку, например `203.0.113.25`;
- **пароль пользователя root**.

Запиши оба, они нужны дальше.

## Шаг 3. Подключись к серверу

Подключаться будем через «терминал»: окно, куда вводят команды.

**Windows:** нажми клавишу Win, набери `PowerShell` и открой его.
**macOS:** нажми Cmd + Пробел, набери `Терминал` и открой его.

Введи команду, подставив свой IP, и нажми Enter:

```bash
ssh root@203.0.113.25
```

- Если спросит `Are you sure you want to continue connecting?`, напиши `yes` и нажми Enter.
- Потом введи **пароль root**. Пока печатаешь, символы не видны, так и должно быть. Просто введи и нажми Enter.

✅ **Проверка:** строка слева стала похожа на `root@имя-сервера:~#`. Значит, ты на сервере.

**Проверь, что с сервера видны Telegram и Яндекс.** Вставь обе строки разом:

```bash
curl -m 15 -sS -o /dev/null -w 'telegram: %{http_code}\n' https://api.telegram.org
curl -m 15 -sS -o /dev/null -w 'yandex: %{http_code}\n' https://api.music.yandex.net
```

✅ Хорошо, если в обеих строках трёхзначное число (например, `telegram: 302`, `yandex: 404`).
❌ Если вместо числа `000` или `timed out`, этот сервис с сервера недоступен. С таким сервером бот работать не сможет.
Проще всего взять сервер в другом месте (например, в Казахстане), пока его не успели настроить.
Если сервер уже настроен, смотри раздел «Бот совсем не отвечает» в конце.

> [!TIP]
> **Как вставлять команды.** В PowerShell: правая кнопка мыши или Ctrl+V. В Терминале macOS: Cmd+V.
> Вставил команду, нажал Enter и подождал, пока снова появится строка `root@...:~#`. Только после этого вставляй следующую.
>
> **Если закрыл окно,** подключись снова (`ssh root@IP`) и сначала перейди в папку бота: `cd ~/yamusicbot`.

## Шаг 4. Установи Docker и скачай бота

Docker — программа, которая запускает бота со всем нужным внутри. Устанавливать Python и прочее вручную не придётся.

Вставляй по одной команде:

```bash
curl -fsSL https://get.docker.com | sh
```
```bash
apt install -y git
```
```bash
git clone https://github.com/MDFillin/yamusicbot.git
```
```bash
cd ~/yamusicbot
```

✅ **Проверка:** команда `docker compose version` показывает номер версии, а не ошибку.

> [!TIP]
> У многих хостингов есть готовый образ **«Ubuntu + Docker»**. Если выбрал его, первую команду можно пропустить.

<details>
<summary><b>Если Docker не устанавливается или потом не скачиваются образы (бывает на серверах в России)</b></summary>

Иногда сайты Docker недоступны с российских серверов: первая команда падает с ошибкой, а в шаге 6 появляются `403 Forbidden`, `denied` или `timeout`.
Тогда поставь Docker из репозитория Ubuntu и включи зеркало для образов:

```bash
apt update && apt install -y docker.io docker-compose-v2
```
```bash
mkdir -p /etc/docker && echo '{"registry-mirrors": ["https://mirror.gcr.io"]}' > /etc/docker/daemon.json && systemctl restart docker
```

После этого продолжай с команды `apt install -y git`.

</details>

## Шаг 5. Создай файл настроек

Все настройки бота лежат в файле `.env`. Создай его из шаблона и открой в редакторе:

```bash
cp .env.example .env
```
```bash
nano .env
```

Откроется простой текстовый редактор **nano**:
- двигаться по тексту можно **стрелками** (мышь здесь не работает);
- найди строку `BOT_TOKEN=123456789:AAAA...`, сотри пример после `=` и вставь токен из шага 1.
  Должно получиться `BOT_TOKEN=7123456789:AAHk3...` без пробелов и кавычек;
- **сохранить:** Ctrl+O, затем Enter. **Выйти:** Ctrl+X (на Mac тоже Ctrl, не Cmd).

Остальное пока не трогай.

## Шаг 6. Получи токен Яндекс Музыки

Бот работает от имени твоего аккаунта Яндекса, и для этого ему нужен токен Яндекса. Запусти команду:

```bash
docker compose run --rm bot python -m bot.get_token
```

- В первый раз Docker будет 2–5 минут собирать бота и выводить много текста. Это нормально.
- Потом появится **ссылка и код**. Открой ссылку на телефоне или компьютере, войди в **тот аккаунт Яндекса, где есть Плюс**, введи код и разреши доступ.
- В терминале появится строка `YANDEX_MUSIC_TOKEN=y0_...`. Выдели её мышкой целиком и скопируй: в PowerShell правой кнопкой мыши или Ctrl+C, на Mac Cmd+C.

Теперь вставь её в настройки:

```bash
nano .env
```

Найди строку `YANDEX_MUSIC_TOKEN=y0_AgAAAA...` и замени её целиком на скопированную. Сохрани (Ctrl+O, Enter) и выйди (Ctrl+X).

<details>
<summary><b>Если команда выдала ошибку: запасной способ через браузер на компьютере</b></summary>

1. В браузере Chrome/Edge/Яндекс нажми F12, открой вкладку **Network (Сеть)** и поставь галочку **Preserve log (Сохранять журнал)**.
2. В этой же вкладке открой ссылку:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
3. Войди в свой аккаунт Яндекса. Страница быстро перебросит на music.yandex.ru.
4. В списке запросов справа найди тот, в адресе которого есть `access_token=`.
   Токен — это всё, что стоит между `access_token=` и следующим `&`. Он начинается на `y0_`.
5. Впиши его в `.env`: `YANDEX_MUSIC_TOKEN=y0_...`

</details>

## Шаг 7. Первый запуск и твой Telegram ID

Запусти бота:

```bash
docker compose up -d --build
```

Теперь найди своего бота в Telegram по username из шага 1 и нажми **Start**.
Бот ответит примерно так: *«⛔ Этот бот приватный. Ваш Telegram ID: 123456789»*.
Так и задумано: пока бот никого не пускает. Скопируй это число.

Добавь его в настройки:

```bash
nano .env
```

Найди строку `ALLOWED_USERS=` и допиши свой ID: `ALLOWED_USERS=123456789`.
Если ботом будут пользоваться несколько человек, перечисли ID через запятую: `ALLOWED_USERS=123456789,987654321`.
Сохрани, выйди и примени настройки:

```bash
docker compose up -d --force-recreate
```

✅ **Проверка:** снова отправь боту `/start`. Он покажет твой аккаунт Яндекса и справку.
Бот в чате уже работает: напиши название песни или пришли аудиофайл.

> [!IMPORTANT]
> После **любого** изменения `.env` запускай `docker compose up -d --force-recreate`.
> Команда `docker compose restart` новые настройки **не** подхватывает.

## Шаг 8. Включи «Медиатеку» (мини-приложение)

Telegram откроет приложение только по защищённому адресу `https://...`. Получим бесплатный адрес на DuckDNS, а сертификат сервер получит сам.

> [!NOTE]
> Для этого к серверу снаружи должны доходить порты 80 и 443. Проверь командой `ip -4 -br addr`.
> Если у `eth0` адрес вида `192.168.…`, `10.…` или `172.16–31.…`, а в панели хостинга нет файрвола или
> «групп безопасности», порты, скорее всего, закрыты. Тогда пропусти 8.1–8.3 и сделай **8Б** (туннель):
> там ничего открывать не нужно.

### 8.1. Получи бесплатный адрес на DuckDNS

1. Открой **https://www.duckdns.org** и войди любым способом вверху страницы (например, через Google).
2. В поле **sub domain** придумай имя латиницей, например `mymusic2024`, и нажми **add domain**.
3. В строке с новым доменом, в поле **current ip**, впиши **IP своего сервера** и нажми **update ip**.

Теперь адрес `mymusic2024.duckdns.org` ведёт на твой сервер.

> Если у тебя уже есть свой домен, можно взять его: сделай A-запись на IP сервера.

### 8.2. Впиши адрес в настройки

```bash
nano .env
```

Стрелкой вниз спустись **в самый конец файла** и допиши три строки, подставив свой адрес:

```
WEBAPP_URL=https://mymusic2024.duckdns.org
DOMAIN=mymusic2024.duckdns.org
COMPOSE_PROFILES=https
```

Обрати внимание: в `WEBAPP_URL` адрес пишется с `https://`, а в `DOMAIN` без него. Сохрани и выйди.

### 8.3. Перезапусти

```bash
docker compose up -d --build --force-recreate
```

Вместе с ботом запустится **Caddy**. Он сам получит сертификат для `https`, обычно за минуту.

✅ **Проверка 1:** открой в обычном браузере `https://mymusic2024.duckdns.org`.
Должна открыться страница «Откройте через Telegram». Значит, всё работает: вне Telegram приложение и не должно открываться.

✅ **Проверка 2:** закрой и заново открой чат с ботом. Слева от поля ввода появится кнопка **«Медиатека»**. Ещё приложение открывается командой `/app`.

> [!TIP]
> Если адрес не открывается, у хостинга может быть включён файрвол. Открой порты **80** и **443** в панели хостинга.
> Или выполни на сервере `ufw allow 80,443/tcp`: это нужно, если команда `ufw status` пишет `Status: active`.

### 8Б. Вариант без открытых портов: туннель fxTunnel

Туннель: сервер сам подключается к [fxTunnel](https://github.com/mephistofox/fxtun.dev) и получает адрес
`https://имя.fxtun.dev`. Это российский сервис, бесплатный, открывается из России.

1. Зарегистрируйся на **https://fxtun.dev**. В личном кабинете, в разделе **«Токены»**, создай токен. Он начинается с `sk_`.
2. Придумай имя поддомена: 3–32 символа, латиница, цифры и дефис, например `bobik-music`.
3. Если раньше настраивал DuckDNS (шаги 8.1–8.3), убери те настройки и останови Caddy:
   ```bash
   docker compose --profile https down
   sed -i '/^WEBAPP_URL=/d;/^DOMAIN=/d;/^COMPOSE_PROFILES=/d' .env
   ```
4. Допиши настройки. В строке `printf` подставь свой токен и имя вместо `sk_ТОКЕН` и `bobik-music`:
   ```bash
   printf 'FXTUNNEL_TOKEN=%s\nFXTUNNEL_DOMAIN=%s\nCOMPOSE_PROFILES=tunnel\n' 'sk_ТОКЕН' 'bobik-music' >> .env
   ```
5. Запусти:
   ```bash
   docker compose up -d --build --force-recreate
   ```

✅ **Проверка:** `docker compose logs --tail 20 tunnel` показывает `Tunnel established!` и строку `HTTP: https://bobik-music.fxtun.dev`.
Если адрес в этой строке другой, допиши его в `.env` как `WEBAPP_URL=https://…` и снова выполни `docker compose up -d --force-recreate`.

Дальше, как в проверке 2 выше: закрой и открой чат с ботом, появится кнопка **«Медиатека»**.
**При первом открытии** fxTunnel покажет страницу-предупреждение о стороннем сайте. Нажми **«Продолжить»** один раз, дальше приложение само продлевает согласие.

## Шаг 9. Как пользоваться

**В чате с ботом:**

| Что сделать | Что будет |
|---|---|
| написать название трека или исполнителя | поиск с кнопками «скачать» |
| прислать ссылку с music.yandex.ru | трек придёт файлом; альбом или плейлист откроется списком с кнопкой «Скачать всё» |
| прислать аудиофайл (можно несколько) | бот спросит, в какой плейлист загрузить |
| подписать файл `Исполнитель - Название` | эти данные попадут в трек |
| `/likes`, `/playlists` | «Мне нравится» и твои плейлисты |
| `/target` | выбрать плейлист, куда файлы будут загружаться сразу, без вопроса |
| `/newplaylist Название` | создать плейлист |

**В «Медиатеке»** (кнопка слева от поля ввода):
- **Медиатека**: «Мне нравится» и плейлисты. Нажми на трек, и он заиграет. ♥ ставит лайк. **⋯** открывает меню: скачать на телефон, отправить в чат, добавить в плейлист.
- **Поиск**: треки, альбомы, артисты, плейлисты.
- **Загрузка**: выбери плейлист, нажми «Выбрать аудиофайлы», потом «Загрузить». Можно загружать большие файлы, в том числе FLAC.
  На iPhone файлы должны лежать в приложении **«Файлы»**: из медиатеки Apple Music выбрать их нельзя.

> После загрузки Яндекс пару минут обрабатывает файл, только потом трек появляется в плейлисте.

## Шпаргалка: команды на каждый день

Сначала подключись к серверу (`ssh root@IP`) и перейди в папку бота: `cd ~/yamusicbot`.

| Что нужно | Команда |
|---|---|
| посмотреть, что пишет бот (логи) | `docker compose logs --tail 100 -f` (выйти: Ctrl+C, бот продолжит работать) |
| применить изменения в `.env` | `docker compose up -d --force-recreate` |
| остановить бота | `docker compose down` |
| запустить снова | `docker compose up -d` |
| обновить бота до новой версии | `git pull`, затем `docker compose up -d --build` |

Бот сам запускается после перезагрузки сервера. Окно терминала можно спокойно закрывать, бот продолжит работать.

## Если что-то не работает

Сначала всегда смотри логи: `docker compose logs --tail 50 bot`. Обычно там написано, в чём дело.

### Бот совсем не отвечает на `/start`

1. Проверь, что бот запущен: `docker compose ps`.
   В колонке STATUS должно быть `Up`. Если там `Restarting` или бота нет в списке, значит, он падает при запуске: причина в логах.
2. Открой логи: `docker compose logs --tail 30 bot`. Найди строку
   `Бот @имя_бота запущен — пишите ему в Telegram: https://t.me/имя_бота`.
   - Строка есть: убедись, что пишешь **именно этому** боту (открой ссылку из лога).
   - Вместо неё `Telegram отклонил BOT_TOKEN`: токен бота скопирован с ошибкой. Возьми его в @BotFather заново.
   - Вместо неё `Не удалось связаться с Telegram`: см. ниже «Бот не может связаться с Telegram».
3. Поправил `.env`? Применяй изменения только так: `docker compose up -d --force-recreate`.

Если в Яндексе что-то не так (токен неверный, Яндекс не пускает сервер), бот всё равно запустится и в ответ на `/start` объяснит в чате, что делать.

### Бот не может связаться с Telegram

В логах `Не удалось связаться с Telegram (api.telegram.org): ... timeout`, а в `docker compose ps` статус всё время `Up несколько секунд`.
Выясни, кто не видит Telegram: сам сервер или только Docker. Выполни на сервере:

```bash
curl -m 15 -sS -o /dev/null -w '%{http_code}\n' https://api.telegram.org
```

**Ответ `302`: сервер Telegram видит, не видит только Docker.** На некоторых VPS это лечится уменьшением MTU.
Допиши в конец `.env` строку `DOCKER_MTU=1400` и выполни `docker compose up -d --build --force-recreate`.

**Ответ `000` или `timed out`: хостинг не пускает сервер к Telegram.** Выхода два:
- **Другой сервер.** Возьми VPS там, где открываются и Telegram, и Яндекс Музыка, например в Казахстане. Проверь связь командами из шага 3 и повтори установку. На новом сервере это минут 15: токены из старого `.env` можно просто скопировать.
- **Прокси для Telegram.** Подойдёт, если у тебя есть прокси за границей: HTTP или SOCKS5, например на своём зарубежном VPS.
  Допиши в `.env` строку вида `TELEGRAM_PROXY=socks5://логин:пароль@IP:порт` и выполни `docker compose up -d --build --force-recreate`.
  Через прокси пойдут только запросы к Telegram, а Яндекс Музыка по-прежнему будет работать напрямую с российского сервера.

### Частые сообщения

| Что видишь | Что сделать |
|---|---|
| `no configuration file provided` | Ты не в папке бота: выполни `cd ~/yamusicbot` |
| `docker: command not found` | Docker не установился: повтори шаг 4 (там есть запасной способ) |
| при сборке `403 Forbidden`, `denied`, `timeout` про `python` или `caddy` | С сервера недоступен Docker Hub: включи зеркало (шаг 4, раскрывающийся блок) |
| в логах `Ошибка настройки: Не задан BOT_TOKEN` | Не заполнен `.env` (шаг 5) или нет `.env` в папке бота |
| в логах `BOT_TOKEN выглядит неправильно` или `Telegram отклонил BOT_TOKEN` | Скопируй токен из @BotFather заново. Строка должна выглядеть так: `BOT_TOKEN=7123456789:AAH...`, без пробелов и кавычек |
| бот пишет «не может подключиться к Яндекс Музыке» | Токен Яндекса неверный или устарел: повтори шаг 6 и выполни `docker compose up -d --force-recreate`. Если токен точно свежий, Яндекс может не пускать запросы с этого сервера; попробуй сервер в России |
| в логах `Не удалось связаться с Telegram` | См. выше «Бот не может связаться с Telegram» |
| в логах `Conflict: terminated by other getUpdates request` | Этот же бот запущен где-то ещё (например, на твоём компьютере). Останови вторую копию |
| бот пишет «Этот бот приватный» | Твоего ID нет в `ALLOWED_USERS`, или ты забыл `docker compose up -d --force-recreate` |
| нет кнопки «Медиатека», а `/app` пишет «не настроено» | `WEBAPP_URL` не заполнен или не применён: шаг 8.2 и 8.3. Потом перезапусти Telegram |
| в логах туннеля `all endpoints failed` или `unauthorized` | Проверь `FXTUNNEL_TOKEN` в `.env` (без пробелов и кавычек). Если токен верный, с сервера недоступен fxtun.dev |
| `https://...duckdns.org` не открывается | Проверь IP на duckdns.org и открытые порты 80/443. Логи Caddy: `docker compose logs --tail 50 caddy` |
| в «Медиатеке» «Нет доступа» | Твоего ID нет в `ALLOWED_USERS` |
| в «Медиатеке» «Сессия устарела» | Закрой приложение и открой заново |
| треки не скачиваются, «Трек недоступен» | Нет Плюса, или трек недоступен в твоём регионе |
| загрузка файла завершилась ошибкой с текстом от Яндекса | Скопируй текст ошибки и отправь тому, кто дал тебе бота |

## Безопасность

- Файл `.env` содержит **токен бота** и **токен Яндекса**. С ними можно управлять и ботом, и твоей музыкой. Никому их не пересылай.
- В `ALLOWED_USERS` держи только тех, кому доверяешь: они получают доступ к твоему аккаунту Яндекс Музыки через бота.
- **Если токен бота утёк:** в @BotFather выполни `/revoke`, выбери бота, впиши новый токен в `.env` и выполни `docker compose up -d --force-recreate`.
- **Если утёк токен Яндекса:** в настройках Яндекс ID выйди на всех устройствах (это отзовёт старые токены). Потом получи новый токен (шаг 6).
